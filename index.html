Asal Pembuatan Aplikasi

Aplikasi Portal & Absensi DPRT PSI Sumberjaya dirancang dan dibangun secara mandiri untuk mendukung digitalisasi tata kelola organisasi, transparansi kas ranting, serta kedisiplinan absensi kader di wilayah Desa Sumberjaya, Kecamatan Tambun Selatan, Kabupaten Bekasi.

  • Pemrakarsa: Pengurus DPRT PSI Sumberjaya
  • Arsitektur: Web Progressive App (PWA) & Android WebView APK
  • Tahun Rilis: 2026 — Edisi Resmi Ranting Sumberjaya

Alur Pembuatan File Android (.APK)

  1. Siapkan berkas utama aplikasi (index.html, manifest.webmanifest, sw.js, dan ikon resmi).
  2. Bungkus aplikasi menggunakan Android Studio (WebView / Trusted Web Activity) atau pembangun APK berbasis PWA.
  3. Atur izin perangkat Android untuk Kamera (selfie absensi) dan Lokasi GPS (koordinat kehadiran).
  4. Tandatangani berkas dengan Keystore resmi ranting lalu bagikan berkas .APK kepada seluruh Kader terdaftar.
